## 截图建议

- 宽度 1200-1600px
- PNG 或 WebP，单张尽量小于 300KB
- 保持同一套主题和窗口风格
- 裁掉无关区域：账号、邮箱、其他项目、API key
- 如果 DSH Skills Manager 里有其他 skill，建议裁掉或模糊
- 测试项目里的学习进度是虚构的，可以放心展示
