# 初始化试跑示例 · 有基础学习者

这是一次「虚拟学习者」的完整初始化输出，用来展示 skill 生成的文件长什么样。

## 虚拟学习者

| 项目 | 回答 |
|------|------|
| 基础 | 做过约 30 题，掌握数组、链表、哈希表 |
| 薄弱 | 动态规划、图 |
| 语言 | JavaScript |
| 目标 | 面试；没有指定日期 |
| 每天时间 | 1 小时 |
| 难度 | 简单 + 中等为主，困难选做 |
| 模式 | 手写模式 |
| 偏好 | 先自己思考 5-10 分钟，再给提示 |
| 复习 | 每周一次 |

## 生成结果

- **总周期：** 10 周（按基础 20-50 题、每天 1 小时建议）
- **每周节奏：** 5 天学习 + 1 天复习 + 1 天机动
- **每天题量：** 2 题
- **题单：** 当前 Hot 100（2026-11-09 抓取，100 题）
- **排序：** 按专题分组，专题内简单 → 中等 → 困难
- **困难题：** 标 `*`，选做

## 文件说明

| 文件 | 说明 |
|------|------|
| `COACH.md` | 运行时规则 + 学生信息（源文件） |
| `progress.md` | 个性化计划 + 进度 |
| `learning-notes.md` | 三层知识笔记骨架 |
| `hot100-list.md` | 本次使用的题单 |
| `CLAUDE.md` / `AGENTS.md` | 平台原生文件：`COACH.md` 全文（由 COACH.md 生成） |

> 这是一个示例输出，不是让你直接拿去学习的模板。
> 实际使用时，skill 会根据你的回答重新生成。
> 本示例使用 JavaScript；skill 本身支持任何语言（Python / Java / C++ / Go 等）。
