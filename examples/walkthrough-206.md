# 示例：206. 反转链表（手写模式完整带做）

> 这个示例展示一次完整的手写模式教学：读题 → 思考 → 提示 → 写代码 → 审查 → 总结 → 更新笔记。
> 示例代码用 JavaScript；实际教学时按学习者选择的语言改写。

---

## 题目

给你单链表的头节点 `head`，请你反转链表，并返回反转后的链表。

```
输入：1 → 2 → 3 → 4 → 5 → null
输出：5 → 4 → 3 → 2 → 1 → null
```

---

## 老师：先读题

**老师：** 先自己读题。你能用自己的话说一下要求吗？

**学生：** 把链表的指向反过来，返回新的头节点。

**老师：** 对。边界情况有哪些？

**学生：** 空链表？只有一个节点？

**老师：** 很好。这两种情况分别应该返回什么？

**学生：** 空链表返回 null，一个节点返回它自己。

**老师：** 对。现在给你 5 分钟，想想暴力解和不用额外空间的解法分别怎么做。

---

## 学生思考

**学生：** 暴力解是不是把节点存到数组里，再从后往前连？

**老师：** 对，这是一种思路。时间复杂度 O(n)，空间 O(n)。能不能不用额外空间？

**学生：** 用几个指针？

**老师：** 方向对了。想想需要几个指针，分别指向哪里。

---

## 提示分级

### Level 1（方向）

> 你要改变的是每个节点的 `next` 指向。改的时候，原来的 `next` 会怎样？

### Level 2（关键洞察）

> 如果用 `prev` 和 `curr` 两个指针，改 `curr.next = prev` 之后，原来的下一个节点就找不到了。
> 所以还需要一个指针，先把它存起来。

### Level 3（伪代码）

```
prev = null
curr = head
while curr:
    next = curr.next
    curr.next = prev
    prev = curr
    curr = next
return prev
```

**学生：** 懂了，三个指针：prev、curr、next。

**老师：** 那循环里先做哪一步？如果先改 `curr.next`，会丢失什么？

**学生：** 会丢失原来的 next，所以要先存 next。

**老师：** 完全正确。写写看。

---

## 学生写代码

```javascript
var reverseList = function(head) {
    let prev = null;
    let curr = head;

    while (curr !== null) {
        const next = curr.next;
        curr.next = prev;
        prev = curr;
        curr = next;
    }

    return prev;
};
```

---

## 代码审查

**老师：** 结构对了。我们逐项看：

1. **边界：** `head` 为 null 时，循环不执行，返回 `prev = null`，对吗？
2. **单节点：** `curr.next = null`，`prev` 变成该节点，`curr` 变成 null，返回该节点，对吗？
3. **返回值为谁：** 循环结束时 `curr` 是 null，`prev` 是原链表最后一个节点，也就是新头节点。对。
4. **变量命名：** `prev / curr / next` 清晰。
5. **复杂度：** 时间 O(n)，空间 O(1)。达标。

**老师：** 有一个小问题：`const next` 在循环里每次都会重新声明，没问题。但如果有人在循环外也用了 `next`，要注意作用域。这里没问题。

---

## 手动模拟

**老师：** 用 `1 → 2 → 3` 手动走一遍，说出每一步三个指针在哪。

**学生：**

| 步骤 | prev | curr | next | 操作后链表 |
|------|------|------|------|------------|
| 初始 | null | 1 | - | 1→2→3 |
| 1 | null | 1 | 2 | 1→null, 2→3 |
| 2 | 1 | 2 | 3 | 2→1→null, 3 |
| 3 | 2 | 3 | null | 3→2→1→null |
| 结束 | 3 | null | - | 返回 3 |

**老师：** 完全正确。这个模拟说明了你真的理解了指针移动。

---

## 总结

**老师：** 一句话总结这题的核心思路。

**学生：** 用 prev、curr、next 三个指针，边遍历边反转指向。

**老师：** 对。补充：

- **模式：** 链表反转（迭代）
- **时间：** O(n)，每个节点访问一次
- **空间：** O(1)，只用了三个指针
- **易错点：**
  1. 先改 `curr.next` 再存 next → 丢失后续节点
  2. 返回 `curr` 而不是 `prev` → 返回了 null
  3. 忘记处理空链表

**老师：** 和 92. 反转链表 II 有什么区别？

**学生：** 那题只反转一部分，需要先找到位置，再接回去。

**老师：** 对。那题会用到这题的模板，只是多了“拼接”的步骤。
