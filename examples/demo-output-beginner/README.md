# 初始化试跑示例 · 零基础学习者

这是一次「零基础学习者」的完整初始化输出，用来展示 skill 在低基础场景下会怎么安排。

## 虚拟学习者

| 项目 | 回答 |
|------|------|
| 基础 | 做过约 3 题，刚学完 JavaScript 基础语法 |
| 薄弱 | 全部（零基础） |
| 语言 | JavaScript |
| 目标 | 系统学算法，暂不面试 |
| 每天时间 | 1 小时 |
| 难度 | 只做简单 + 中等，困难跳过 |
| 模式 | 手写模式 |
| 偏好 | 先自己思考 5-10 分钟，再给提示 |
| 复习 | 每周一次 |

## 生成结果

- **总周期：** 12 周（零基础特例）
- **第 1 周：** 热身周，先补 JavaScript 基础 + 4 道简单题（1, 136, 169, 448）
- **每周节奏：** 4 天学习 + 1 天复习 + 2 天机动
- **每天题量：** 1-2 题
- **计划范围：** 87 题（去掉 13 道困难题）
- **排序：** 按专题分组，专题内简单 → 中等 → 困难
- **困难题：** 全部跳过，不安排

## 和「有基础」示例的区别

| 维度 | 有基础 | 零基础 |
|------|--------|--------|
| 周期 | 10 周 | 12 周 |
| 每天题量 | 2 题 | 1-2 题 |
| 第一周 | 直接进入哈希/数组 | 热身周：JS 基础 + 4 道简单题 |
| 困难题 | 标 `*` 选做 | 全部跳过 |
| 计划范围 | 100 题 | 87 题 |

## 文件说明

| 文件 | 说明 |
|------|------|
| `COACH.md` | 运行时规则 + 学生信息（自包含） |
| `progress.md` | 个性化计划 + 进度 |
| `learning-notes.md` | 三层知识笔记骨架（含热身周提醒） |
| `hot100-list.md` | 本次使用的题单（困难题标为跳过） |
| `CLAUDE.md` / `AGENTS.md` | 平台指针，指向 `COACH.md` |

> 这是一个示例输出，不是让你直接拿去学习的模板。
> 实际使用时，skill 会根据你的回答重新生成。
