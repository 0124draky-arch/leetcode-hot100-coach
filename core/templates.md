# 学习文档生成规则

> 初始化时生成四个核心文档 + 平台指针文件。
> 具体模板见 `assets/` 目录。

---

## 1. 占位符规则

- 模板中的 `{{...}}` 必须在生成时全部替换
- 不能把 `{{...}}` 留给用户
- 日期统一用 `YYYY-MM-DD`
- 用户的回答要转述成简洁的书面语，不要原样堆砌

---

## 2. 生成顺序

```
1. hot100-list.md       # 先确定题单
2. COACH.md             # 再写教学规则 + 学生信息
3. progress.md          # 根据题单和计划生成
4. learning-notes.md    # 生成骨架
5. CLAUDE.md / AGENTS.md（如果平台支持）
```

---

## 3. COACH.md

**作用：** 运行时唯一事实来源。

**组成：**

```
学生信息
  +
学习模式
  +
计划摘要
  +
core/coach.md 的完整内容
  +
平台无关约定
```

**模板：** `assets/coach-template.md`

**必须包含：**

- 学生背景（已做题量、掌握专题、薄弱专题、语言）
- 目标（面试 / 系统学 / 兴趣）
- 每天可投入时间
- 当前模式（手写 / 只讲思路）
- 难度范围
- 计划摘要（周期、每周节奏、每天题量）
- 题单文件位置
- 完整教学规则
- 存档 / 读档规则
- 文档更新规则
- 红线

**注意：** `COACH.md` 必须是自包含的，不能只写“见 skill 的 core/coach.md”。因为初始化后 skill 可能不在旁边。

---

## 4. progress.md

**作用：** 记录计划、进度、薄弱点，支持读档。

**模板：** `assets/progress-template.md`

**必须包含：**

- 当前状态（阶段、最后更新、模式）
- 学习计划（按周 / 按批）
- 已完成题目（题号、标题、日期、一句话思路）
- 当前任务
- 下一步
- 薄弱点（⭐）
- 学习心得
- 存档说明

**更新规则：**

- 每完成一题：更新已完成列表和当前任务
- 存档时：完整读取后更新，不要只改局部
- 调整计划时：保留历史完成记录

---

## 5. learning-notes.md

**作用：** 三层知识库。

**模板：** `assets/notes-template.md`

**三层结构：**

```
第一部分：核心思路模板
  - 按模式分类（哈希、双指针、滑动窗口、链表、栈、树、图、DP）
  - 每个模板：适用场景、核心思路、代码模板、复杂度

第二部分：JavaScript 基础
  - 遇到再补，不追求系统完备
  - Map / Set / Array / String / 循环 / 函数

第三部分：题目详解
  - 题号、标题、难度、完成日期
  - 核心思路
  - 代码
  - 复杂度
  - 易错点
  - 学习心得
```

**掌握标记：**

- ✅ 已掌握
- ⭐ 需要复习
- ❓ 没懂

---

## 6. hot100-list.md

**作用：** 锁定本次初始化使用的题单，方便追溯。

**模板：** `assets/hot100-list-template.md`

**必须包含：**

- 来源 URL
- 获取日期
- 题目总数
- 难度分布
- 完整题单表格（题号、中文标题、难度、专题、slug、状态、备注）
- 专题用于生成学习计划的分组，写法见 `core/onboarding.md` 的「主题分组与排周」

---

## 7. 平台指针文件

### CLAUDE.md（Claude Code）

```markdown
# Hot 100 学习项目

请读取并遵循本目录的 `COACH.md`。

- 每次对话开始：读取 `COACH.md`、`progress.md`、`learning-notes.md`
- 存档：更新 `progress.md` 和 `learning-notes.md`
- 读档：按 `COACH.md` 的流程恢复
```

### AGENTS.md（Codex / 通用 agent）

内容同 `CLAUDE.md`。

### .cursorrules（Cursor）

内容同 `CLAUDE.md`。

> 指针文件只做一件事：让平台自动加载，然后转去读 `COACH.md`。
> 不要把完整规则复制到多个文件，避免漂移。

---

## 8. 生成后校验

- [ ] 所有 `{{...}}` 已替换
- [ ] `COACH.md` 包含完整规则，不只是指针
- [ ] `progress.md` 的计划和用户确认的一致
- [ ] `learning-notes.md` 三层结构齐全
- [ ] `hot100-list.md` 有来源、日期、难度分布、完整表格
- [ ] 指针文件指向 `COACH.md`
- [ ] 文件名和大小写正确

---

## 9. 纯聊天模式的输出方式

如果平台不能写文件：

1. 按文件名分块输出
2. 每块用代码块包裹
3. 告诉用户：

> 我没有文件写入能力，下面是四个文件的内容，请分别保存：
> - `COACH.md`
> - `progress.md`
> - `learning-notes.md`
> - `hot100-list.md`
>
> 下次新对话时，把 `COACH.md`、`progress.md`、`learning-notes.md` 贴回来即可继续。

---

## 10. 文件位置

默认放在用户当前学习目录的根目录：

```
<学习目录>/
├── COACH.md
├── progress.md
├── learning-notes.md
├── hot100-list.md
├── CLAUDE.md
└── AGENTS.md
```

如果用户想放到子目录（例如 `hot100/`），按用户指定的位置生成，并在 `COACH.md` 中记录路径。
