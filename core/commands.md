## 3. 维护与调整

### ✅ 已支持

| 用户说 | 功能 | 行为 | 定义位置 |
|--------|------|------|----------|
| “更新题单” / “题单变了” / “检查最新 Hot 100” | 更新题单 | 读当前 `hot100-list.md` → 尝试 GraphQL → 网络被拦截则手动粘贴 → 对比差异 → 确认 → 更新 | `core/coach.md` §10.1、`core/update.md` §1 |
| “太快了” / “太慢了” / “没时间” / “想加量” | 调整计划 | 读进度 → 计算实际完成 → 给建议 → 确认 → 更新 `progress.md` | `core/update.md` §2 |

| “困难题也加上” / “困难题先跳过” | 调整难度 | 重新计算题量 → 更新 `COACH.md` 和 `progress.md` → 同步原生文件 | `core/update.md` §4 |
| “换成 Python” / “换语言” | 换语言 | 更新 `COACH.md` 语言字段 → 重写笔记语言部分和代码模板 → 同步原生文件 | `core/update.md` §5 |

## 6. 内部自动动作

| 动作 | 触发 | 行为 |
|------|------|------|
| 检查是否已初始化 | 每次触发 skill | 检查 `COACH.md` / `progress.md` / `learning-notes.md` |
| 获取题单 | 初始化 / 更新题单 | GraphQL → 快照 → 用户粘贴 |
| 生成个性化计划 | 初始化 / 调整计划 | 周期计算 → 难度过滤 → 专题分组 → 按周切分 → 困难题标记 |
| 生成学习文档 | 初始化 | `COACH.md`、`progress.md`、`learning-notes.md`、`hot100-list.md` |
| 生成平台原生文件 | 初始化 | `CLAUDE.md` / `AGENTS.md` / `.cursorrules`（完整规则） |
| 同步原生文件 | `COACH.md` 变更 | 重新生成对应平台文件 |
| 存档自动提交 | 用户说“存档” | 更新文档 → `git add` 相关文件 → commit |
| 语言适配 | 初始化 / 换语言 | 代码模板、笔记、语法说明按用户语言生成 |
| 平台适配 | 初始化 | 按当前平台生成入口文件 |
| 复习标记维护 | 复习 | ✅ 已掌握 / ⭐ 需复习 / ❓ 没懂 |

## 7. 指令设计原则

1. **自然语言优先**：用户不需要记精确说法，意思对即可
2. **基本操作只有 4 个**：初始化、读档、存档、复习
3. **维护操作可随时说**：更新题单、调整计划、切换模式、换语言
4. **不触发场景要明确**：单题提问、普通开发需求不要走初始化
5. **网络/工具被拦截时降级**：不反复重试，直接进入手动模式
